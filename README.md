이것은 트릭컬 리바이브 2차 창작 테마 극장. 
=
## 제목: 하늘로 뿌리내린 가지.
### 시놉시스
- 등장인물 스페럿, 교주, 그윈, 델리아, 콰르한
- 테마 외지인이라는 정체성 (교주와 엘프들은 엘리아스 밖에서 온 외지인, 콰르한은 교단의 사제가 되고 싶었지만 우로스 사태로 도망쳐 나온 샤먼(정착했지만 어느쪽에도 속하지 않는 듯한 감각))
- 플롯 콰르한은 교주를 향해 자격지심을 보이고 교주일행이 그것을 이해해 주고 받아 들임
- 기 글레이시아를 찾은 교주 일행은(아직 스토리가 공개되진 않았지만 찾은 것으로 함) 주변 탐색을 하던 중 고래 해적들에 의해 빵주가 고장나고 콰르한이 있는 초원에 불시착, 초원지대에서 호전적인 수인 부족들로 부터 공격을 받을 뻔하다가 콰르한의 도움으로 살아남음 콰르한을 통해 초원 지대의 생활상을 소개 받음. 교주의 존재를 알게 되자 과거 장면 오버랩
- 승 교단의 사제가 되고 싶었던 과거로 인해, 현재 믿음에 대해 회의감이 있음에도 자신에게 샤먼이라는 정체성을 강조하며 신기한 묘술을 선보임, 시간이 흐르면서 빵주는 수리되고 자신의 가치를 증명할수 있는 시간이 줄어 들기 시작하면서 불안감을 느낌 전 자격지심이 강해지면서 교주 일행을 상대로 폭언을 하게 되고 떠남. 이후 호전적인 부족들이 빵주를 공격할 때 콰르한이 먼저 나서서 그들을 구해줌
- 결 빵주는 항해할 준비를 하였고 콰르한은 자격지심을 벗어 던지고 교단에 입교를 신청, 안된다면 조력자라도 되게 해달라 함. 교주는 입교를 받아들이고 초원지대에서 교단 지부를 세움.
